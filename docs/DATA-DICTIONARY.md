# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

## 结算计价定义

**定稿口径：入账金额按损失时段实际生效费率逐段计价。** 夜班要求的“整张责任单沿用指令下达时费率”作为对照口径保留并同屏展示，不并入入账金额。依据：

- 财务要求金额可逐段追到损失时段实际生效费率，这是唯一能与账单逐段对查的口径；
- 费率表是运营方与结算方共享的同一份事实，按生效区间取价可复核、可重放；
- 指令口径在跨费率变更时会把变更后的时段按旧价计价，得到的是不可入账的近似值，只能作差异说明；
- 因此两种口径的差额单列为 `difference_cny`，不隐藏、不互相覆盖。

**费用片段切分**：以能量片段（`energy_rows`）为基础，再按费率的起止边界切分。费率取该片段起点时刻、对该设备区域生效的费率。区域专用费率优先于全局费率；同一时刻存在多个不同有效费率判 `TARIFF_CONFLICT`，该片段待核。

**逐段计价**：`片段金额 = 片段损失 × 片段费率`，保留0.01元。片段损失按秒数分摊并量化到0.0001kWh（用累计量取整后相减，天然单调非负），保证片段损失之和等于能量片段损失、片段金额之和等于入账总额，总额可逐段解释。

**指令口径**：责任单按设备并集分组，取该组内最早事件的下达时点（`instruction_times`，缺省为事件开始时刻）的费率，对整组损失一次性计价。指令时点缺失、协同事件指令费率不一致、组内损失未定，都判为指令口径未定。

**同一损失只计价一次**：并集已消除重叠，费用片段按主责任单归属一次（主责任单=最早下达指令者，其次编号），协同事件只记录在 `shared_with`，不另立金额。各责任单合计之和等于入账总额。

**待核**：以下片段金额为 `null`、不计入入账金额，也不填0：`NO_REFERENCE`/`TARGET_GAP` 等损失未定；`NO_TARIFF`、`TARIFF_INVALID`、`TARIFF_CONFLICT` 等费率冲突或证据不足。存在待核片段时整批状态为“待核”，归档被阻断；已计价部分的金额以 `priced_amount_cny` 单独展示，不作为可入账总额（`bookable_amount_cny` 为 null）。待核片段含未定损失时，待核损失合计同样为 null，不呈现为 0。

**样例数值**：费率在10:15由0.30切到0.40。清批逐段实际费率合计9.17元；指令口径（整单0.30）合计8.00元，差额1.17元。全部费用片段7段，与能量片段一致，待核0段。
